    Dados e backup

    Tudo fica salvo só neste navegador. Se você limpar os dados do navegador, perde o diário. Faça backup de vez em quando.

    Painel educacional. Não envia ordens e não é recomendação de investimento. Futuros com alavancagem podem causar perdas maiores que o valor investido. Dados de mercado: API pública da Binance.
